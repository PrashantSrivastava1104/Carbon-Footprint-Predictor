# Data Directory

## raw/

Contains the raw dataset `Carbon Emission.csv`.

**Source:** [Individual Carbon Footprint Calculation](https://www.kaggle.com/datasets/dumanmesut/individual-carbon-footprint-calculation)
**Author:** Mesut Duman
**License:** CC0 1.0 Public Domain (free to use, modify, distribute)

> **IMPORTANT:** This dataset is **synthetically generated** from a
> deterministic formula, not from real individual surveys. The high R² values
> achieved by the model (Test R² = 0.9721 for XGBoost) are a consequence of
> this: the model essentially re-learns the underlying formula.

**How to get the data:**
1. Create a free Kaggle account at https://www.kaggle.com
2. Go to the dataset URL above
3. Click "Download" → save `Carbon Emission.csv` to this folder (`data/raw/`)

**Shape:** 10,000 rows × 20 columns
**Target column:** `CarbonEmission` — yearly kg CO₂e per person (divided by 12 in preprocessing)

## processed/

Contains `cleaned_data.csv` — auto-generated by `python src/train.py`.
Do not edit manually; regenerate by re-running the training script.
